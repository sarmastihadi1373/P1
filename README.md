# Manim Animations - Circle Scene

Welcome to my Manim animation project! This repository contains Python scripts for creating mathematical and geometric visual animations using the Manim engine.

## Project Overview
This project demonstrates a simple circle animation created with Manim:
* Scene Name: CreateCircle
* Features: Creates a pink circle with 50% opacity and animates its appearance.

## Built With
* Language: Python
* Library: Manim

## How to Run Locally

1. Clone the repository:
   git clone https://github.com/sarmastihadi1373/P1.git

2. Install Manim:
   pip install manim

3. Render the animation:
   manim -pql "Manim 1.py" CreateCircle
